# Описание

Сервис обработки заказов. Версия Golang 1.22

## Назначение

Сервис рассчитывает итоговую стоимость товаров в корзине с учётом скидок.

## Правила расчёта

1. Базовая стоимость — сумма `price * quantity` по всем позициям.
2. Процентная скидка по типу клиента:
   - `VIP` — 10 %;
   - `NEW` — 5 %;
   - `REGULAR` и прочие — без скидки.
3. Если суммарное количество единиц товара в заказе больше 10 — дополнительная
   скидка 1 %.
4. Если итоговая сумма превышает 1000 — фиксированная скидка 50.

Скидки применяются последовательно в указанном порядке.

## Структура

- `internal/order` — домен заказа: товары, тип клиента, правила скидок и сервис расчёта.
- `main.go` — демонстрация использования сервиса.
